# CABJATRA — Premium Cab Booking & Odisha Travel Platform

**CABJATRA** is a premium pre-booked chauffeur mobility and Odisha travel platform built with Next.js 15 (App Router), React 19, TypeScript, and Tailwind CSS. The platform connects domestic and international travelers, pilgrims, and corporate professionals with background-verified commercial chauffeurs and clean, air-conditioned fleet across Odisha.

---

## Key Features

- **Iconic Odisha Visual Storytelling**: Authentic imagery celebrating UNESCO World Heritage Konark Sun Temple, Puri Jagannath Dham, Marine Drive, and Chilika Lagoon.
- **Pre-Booked Chauffeur Dispatch (`/book-cab`)**:
  - Interactive 4-step concierge booking terminal (Route, Vehicle Selection, Passenger Info, Boarding Pass Review).
  - Real-time route distance preview, travel duration, and transparent 10% advance deposit breakdown.
  - Standardized commercial fleet categories: Sedans, Innova Crysta SUVs, Kia Carens, and Tempo Travellers.
- **Curated Odisha Tours (`/book-tour`)**:
  - Visual-first tour circuits (Golden Triangle Classic, Puri Same-Day Splendor, Chilika Dolphin Eco-Trail).
  - Interactive day-by-day timeline tabs with concise sightseeing stops.
  - Visual inclusion chips (all fuel, tolls, FASTag, driver allowance, and temple waiting buffers included).
- **Dedicated Mobility Verticals**:
  - Punctual Biju Patnaik International Airport (BBI) transfers with flight radar tracking.
  - Outstation highway one-way and round-trip journeys across all 30 Odisha districts.
  - Flexible 4, 8, and 12-hour local city hourly rentals.
  - Corporate mobility and institutional transport with GST invoicing.
- **10% Advance Deposit Model**:
  - Booking requests do not lock funds upfront. Only 10% advance is deposited upon vehicle and driver allocation check; remaining 90% is settled after arrival.
- **Interactive Design & Skeuomorphic Refinements**:
  - Bespoke vector brand emblem combining the 24-spoke Konark chariot wheel with a luxury compass star.
  - Floating frosted-glass capsule navbar with smooth mega-menu dropdown.
  - Luxury 4-tier footer with live concierge dispatch ribbon, click-to-copy phone and email, active operating hub badges, and NovaSpark Digital Marketing attribution.
  - 3D floating WhatsApp concierge button with live status pulse.

- **Icons**: Lucide React
- **Fonts**: Plus Jakarta Sans & Playfair Display

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or the active port assigned) in your browser.

### 3. Build for Production
```bash
npm run build
npm start
```
